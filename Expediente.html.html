01

Descripción del proceso

EXPLICACIÓN DEL PROCESO A AUTOMATIZAR

El proyecto consiste en desarrollar un estacionamiento inteligente automatizado mediante Arduino, cuyo objetivo principal es controlar el acceso de los vehículos.

El proceso comenzará cuando un automóvil llegue a la entrada del estacionamiento. Un sensor detectará la presencia del vehículo y permitirá que se abra la puerta de acceso para que pueda ingresar. El sistema estará diseñado únicamente para facilitar la entrada del automóvil de manera automática.

Una vez que el automóvil se estacione en el espacio correspondiente, los sensores detectarán si el lugar está ocupado. Mediante fotorresistencias y sensores, el sistema podrá identificar la presencia del vehículo y mostrar su estado a través de dos LEDs: el LED rojo se encenderá cuando el espacio esté vacío, mientras que el LED verde se encenderá cuando se detecte un automóvil estacionado.

De esta manera, el proyecto permitirá controlar automáticamente la apertura de la puerta y conocer de forma visual si el espacio de estacionamiento está disponible u ocupado. Todo el funcionamiento se realizará utilizando únicamente sensores, fotorresistencias y LEDs.

02

Problema o necesidad

SITUACIÓN ACTUAL Y RAZÓN PARA AUTOMATIZAR

Actualmente, en algunos estacionamientos, la entrada de los vehículos y la identificación de los espacios disponibles pueden realizarse de manera manual. Esto puede provocar que los conductores tengan que abrir la puerta por su cuenta o que sea difícil identificar rápidamente si un espacio está ocupado o vacío.

La necesidad detectada es contar con un sistema que permita facilitar el acceso de los automóviles y detectar automáticamente la presencia de un vehículo en el espacio de estacionamiento. De esta manera, se podrá conocer visualmente si el lugar está disponible o si se encuentra ocupado mediante el uso de LEDs.

Por esta razón, se propone desarrollar un sistema automatizado utilizando Arduino, sensores y fotorresistencias. El sistema detectará cuando un automóvil llegue a la entrada para permitir la apertura de la puerta y, una vez que el vehículo se estacione, identificará su presencia para encender un LED verde cuando haya un automóvil y un LED rojo cuando el espacio esté vacío. Esto permitirá hacer más práctico y organizado el funcionamiento del estacionamiento.

03

Objetivo general

RESULTADO PRINCIPAL QUE SE PRETENDE ALCANZAR

El principal resultado que se pretende alcanzar es desarrollar un prototipo funcional de un estacionamiento automatizado utilizando Arduino, sensores y fotorresistencias, capaz de detectar la presencia de un automóvil y controlar la apertura de la puerta de acceso.

Con este proyecto se busca demostrar que es posible automatizar el acceso y la detección de los espacios de estacionamiento. Cuando un automóvil llegue a la entrada, el sistema permitirá abrir la puerta y, una vez que el vehículo se estacione, los sensores detectarán su presencia. El LED verde indicará que hay un automóvil en el espacio, mientras que el LED rojo indicará que el espacio se encuentra vacío.

De esta manera, se pretende obtener un sistema sencillo, práctico y funcional que permita identificar visualmente el estado del estacionamiento mediante sensores, fotorresistencias y LEDs.

04

Objetivos específicos

ACCIONES CONCRETAS

  1. Implementar detección automática: configurar el sensor ultrasónico para identificar con precisión la llegada del vehículo frente a la pluma.
  2. Automatizar apertura y cierre: programar el servomotor para levantar y bajar la barrera en intervalos definidos, garantizando el paso seguro del coche.
  3. LEDs verde y rojo: mostrar con LEDs si el lugar está ocupado o no, ya sea con luz roja o verde.

Entradas y salidas

ENTRADAS

  • Sensor de entrada: detectará cuando un automóvil llegue a la entrada del estacionamiento para activar el mecanismo de apertura de la puerta.
  • Sensor de estacionamiento: detectará si hay un automóvil en el espacio de estacionamiento.
  • Fotorresistencia: ayudará a detectar la presencia del automóvil mediante los cambios en la cantidad de luz recibida.
  • Arduino: recibirá las señales de los sensores y la fotorresistencia para procesar la información y controlar las salidas del sistema.

SALIDAS

  • Servomotor: se encargará de abrir la puerta de acceso cuando se detecte un automóvil en la entrada.
  • LED verde: indicará que hay un automóvil estacionado en el espacio.
  • LED rojo: indicará que el espacio de estacionamiento se encuentra vacío.

Selección de sensores y actuadores

COMPONENTE ELEGIDO: ARDUINO UNO

Características básicas:

  • Microcontrolador: ATmega328P.
  • Voltaje de funcionamiento: 5 V.
  • Cuenta con entradas y salidas digitales para conectar sensores, LEDs y otros componentes.
  • Tiene entradas analógicas que permiten trabajar con dispositivos como las fotorresistencias.
  • Permite controlar un servomotor mediante programación.
  • Se puede programar fácilmente mediante el entorno de Arduino.

Justificación de su elección:

Se eligió Arduino Uno porque es una placa sencilla de utilizar y adecuada para desarrollar el prototipo de un estacionamiento automatizado. Permite recibir las señales de los sensores y la fotorresistencia, procesar la información y controlar las salidas del sistema.

En este proyecto, Arduino será el encargado de detectar cuando un automóvil llegue a la entrada, activar el servomotor para abrir la puerta y determinar si el espacio de estacionamiento está ocupado o vacío. Dependiendo de la información recibida, también controlará los LEDs para indicar el estado del espacio: verde cuando haya un automóvil y rojo cuando esté vacío.

Además, Arduino fue elegido porque permite integrar todos los componentes del proyecto en un solo sistema y facilita la programación y realización de pruebas del prototipo.

Algoritmo / pseudocódigo

PASOS LÓGICOS DEL PROGRAMA DE CONTROL

  1. Iniciar el sistema: Arduino comenzará a funcionar y configurará los sensores, la fotorresistencia, el servomotor y los LEDs.
  2. Esperar la llegada de un automóvil: el sistema permanecerá monitoreando el sensor ubicado en la entrada.
  3. Detectar el automóvil: cuando el sensor detecte un vehículo, Arduino recibirá la señal y activará el servomotor.
  4. Abrir la puerta: el servomotor moverá la puerta para permitir el acceso del automóvil al estacionamiento.
  5. Detectar el espacio de estacionamiento: la fotorresistencia y el sensor verificarán si hay un automóvil ocupando el espacio.
  6. Indicar el estado del espacio: si se detecta un automóvil, Arduino encenderá el LED verde. Si no se detecta ningún automóvil, permanecerá encendido el LED rojo.
  7. Actualizar constantemente: el sistema continuará leyendo los sensores para detectar cualquier cambio en el estado del estacionamiento.
  8. Repetir el proceso: después de cada detección, Arduino volverá a esperar la llegada de otro automóvil y repetirá el proceso automáticamente.

Riesgos y seguridad

RIESGOS Y MEDIDAS PREVENTIVAS

  • Conexiones incorrectas: revisar cuidadosamente las conexiones antes de encender el circuito para evitar daños en los componentes.
  • Daño de los LEDs o sensores: utilizar las resistencias adecuadas y conectar cada componente correctamente.
  • El sensor no detecta el automóvil: colocar el sensor a una distancia adecuada y realizar varias pruebas para comprobar su funcionamiento.
  • La fotorresistencia no detecta correctamente el vehículo: verificar su posición y probarla con diferentes condiciones de iluminación.
  • El servomotor no abre la puerta correctamente: revisar sus conexiones y asegurarse de que la puerta de la maqueta sea ligera y pueda moverse fácilmente.
  • Errores en la programación: revisar el código de Arduino y realizar pruebas individuales de cada componente antes de unir todo el sistema.
  • Daño de los componentes durante el armado: manipular los componentes con cuidado y desconectar la alimentación antes de modificar las conexiones.
17

Criterios de éxito

CONDICIONES MEDIBLES PARA CONSIDERAR FUNCIONAL EL PROYECTO

  • El sensor de entrada deberá detectar un automóvil cuando se coloque frente a la puerta.
  • El servomotor deberá abrir la puerta correctamente al detectar el automóvil.
  • La puerta deberá abrirse y cerrarse sin atorarse durante las pruebas.
  • La fotorresistencia y el sensor de estacionamiento deberán detectar correctamente cuando haya un automóvil en el espacio.
  • El LED verde deberá encenderse cuando se detecte un automóvil estacionado.
  • El LED rojo deberá encenderse cuando el espacio se encuentre vacío.
  • El sistema deberá responder correctamente en al menos 8 de cada 10 pruebas realizadas.
  • Todos los componentes deberán funcionar de manera conjunta sin presentar fallas durante las pruebas.
