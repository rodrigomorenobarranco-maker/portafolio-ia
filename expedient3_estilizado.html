Estacionamiento inteligente

1. Descripción del proceso

El proyecto consiste en desarrollar un estacionamiento inteligente automatizado mediante Arduino, cuyo objetivo principal es controlar el acceso de los vehículos.

Cuando un automóvil llegue a la entrada, un sensor detectará su presencia y permitirá abrir automáticamente la puerta de acceso. Una vez que el automóvil se estacione, los sensores y la fotorresistencia identificarán si el espacio está ocupado.

Funcionamiento visual: el LED verde indica que hay un automóvil estacionado y el LED rojo indica que el espacio está vacío.

2. Problema o necesidad

En algunos estacionamientos, la entrada de vehículos y la identificación de espacios disponibles se realizan manualmente. Esto puede obligar al conductor a abrir la puerta por su cuenta o dificultar la identificación rápida de un espacio libre.

Se necesita un sistema que facilite el acceso y detecte automáticamente la presencia de un vehículo, mostrando el estado del espacio por medio de LEDs.

Razón para automatizar

  • Facilitar el acceso de los automóviles.
  • Identificar visualmente si el espacio está ocupado o vacío.
  • Hacer más práctico y organizado el funcionamiento del estacionamiento.

3. Objetivo general

Desarrollar un prototipo funcional de un estacionamiento automatizado utilizando Arduino, sensores y fotorresistencias, capaz de detectar la presencia de un automóvil y controlar la apertura de la puerta de acceso.

Resultado esperado: obtener un sistema sencillo, práctico y funcional que automatice el acceso y permita identificar visualmente el estado del estacionamiento.

4. Objetivos específicos

  1. Configurar el sensor para identificar con precisión la llegada del vehículo frente a la pluma.
  2. Programar el servomotor para levantar y bajar la barrera en intervalos definidos.
  3. Utilizar LEDs verde y rojo para mostrar si el lugar está ocupado o disponible.
  4. Realizar pruebas individuales y conjuntas de todos los componentes.

7. Selección de componentes

Arduino Uno

  • Microcontrolador ATmega328P.
  • Voltaje de funcionamiento de 5 V.
  • Entradas digitales y analógicas.
  • Permite conectar sensores, LEDs y fotorresistencias.
  • Controla el servomotor mediante programación.

Se eligió por ser una placa sencilla, accesible y adecuada para integrar todos los componentes del prototipo.

8. Diagrama de bloques y conexión

El sistema recibe señales de los sensores, las procesa mediante Arduino y activa el servomotor o los LEDs según el estado detectado.

12. Riesgos y seguridad

  • Revisar conexiones antes de encender el circuito.
  • Utilizar resistencias adecuadas para proteger los LEDs.
  • Colocar los sensores a una distancia correcta.
  • Probar la fotorresistencia con diferentes condiciones de iluminación.
  • Desconectar la alimentación antes de modificar conexiones.
  • Verificar que la puerta sea ligera y no se atore.

13. Criterios de éxito

  • El sensor detecta un automóvil frente a la puerta.
  • El servomotor abre y cierra correctamente.
  • La fotorresistencia detecta la ocupación del espacio.
  • El LED verde indica automóvil estacionado.
  • El LED rojo indica espacio vacío.
  • El sistema responde correctamente en al menos 8 de cada 10 pruebas.
