Estacionamiento inteligente — planeación del proyecto

Expediente técnico de planeación para un estacionamiento automatizado con Arduino, capaz de detectar la entrada y salida de vehículos, medir el tiempo de permanencia y calcular el costo correspondiente de forma automática.

1. Descripción del proceso

El proyecto consiste en desarrollar un estacionamiento inteligente automatizado mediante Arduino, cuyo objetivo principal es controlar el acceso de los vehículos y calcular el costo de estacionamiento de acuerdo con el tiempo que cada automóvil permanezca dentro.

El proceso comienza cuando un automóvil llega a la entrada: un sensor detecta su presencia y Arduino registra la hora de entrada. El vehículo ingresa y el sistema comienza a contar el tiempo de permanencia. Al salir, otro sensor detecta el vehículo y Arduino registra la hora de salida; con ambos datos calcula el tiempo total y, mediante una tarifa establecida, determina cuánto debe pagar el usuario.

De esta manera, el proceso que normalmente realizaría una persona —registrar entrada, controlar el tiempo, registrar salida y calcular el precio— se ejecuta automáticamente, haciendo el estacionamiento más organizado, rápido y eficiente, y reduciendo errores en el cobro.

2. Problema o necesidad

En muchos estacionamientos, el control del tiempo de permanencia y el cálculo del costo se hacen de forma manual, lo que puede generar errores al registrar la hora de entrada o salida y requiere atención constante de una persona encargada.

La necesidad detectada es contar con un sistema que controle automáticamente el ingreso y salida de vehículos, registre el tiempo de permanencia y calcule el costo correspondiente, facilitando la administración y dando resultados más rápidos y precisos.

Se propone automatizar el proceso mediante Arduino, sensores y componentes electrónicos, reduciendo errores humanos y agilizando el cobro.

3. Objetivo general

Desarrollar un prototipo funcional de estacionamiento inteligente con Arduino, capaz de detectar automáticamente la entrada y salida de vehículos, registrar el tiempo de permanencia y calcular el costo correspondiente.

Con este proyecto se busca demostrar que es posible automatizar el control y cobro de un estacionamiento, haciendo el proceso más rápido, preciso y eficiente, reduciendo la necesidad de cálculos manuales.

4. Objetivos específicos

  1. Implementar detección automática: configurar el sensor ultrasónico para identificar con precisión la llegada del vehículo frente a la pluma.
  2. Automatizar apertura y cierre: programar el servomotor para levantar y bajar la barrera en intervalos definidos, garantizando el paso seguro del coche.
  3. Registrar hora de entrada: diseñar el código en Arduino que guarde el momento exacto en que el vehículo accede al estacionamiento.
  4. Calcular tiempo y cobro: implementar la lógica que mida la permanencia del coche y aplique tarifas según bloques de tiempo establecidos.
  5. Mostrar información al usuario: configurar la pantalla LCD para desplegar en tiempo real los minutos transcurridos y el monto a pagar.

7. Entradas y salidas

El sistema recibe información mediante sensores y botones, que permiten detectar cuándo un automóvil entra o sale del estacionamiento y controlar algunas funciones del sistema.

Entradas

  • Sensor de entrada: detecta cuando un automóvil llega al estacionamiento.
  • Sensor de salida: detecta cuando un automóvil abandona el estacionamiento.
  • Botones: controlan funciones como iniciar, reiniciar o simular el proceso de entrada y salida.
  • Arduino: recibe las señales de los sensores y botones para procesar la información.

Salidas

  • Servomotor: abre y cierra la barrera de acceso cuando se detecta un vehículo.
  • LEDs: indican estados del sistema (entrada, salida, disponibilidad, cobro).
  • Pantalla LCD: muestra el tiempo de permanencia y el monto a pagar.
  • Alarma o buzzer: emite un sonido para indicar acciones o avisos del sistema.

9. Diagrama de bloques

El Arduino Uno actúa como bloque central: recibe la señal del sensor ultrasónico HC-SR04, procesa la lógica de tiempo y tarifa, y activa las salidas correspondientes — el servomotor SG90 para la pluma, los LEDs indicadores, el buzzer y la pantalla LCD.

El prototipo se validó primero en un simulador (Tinkercad) antes de armar la maqueta física, para revisar conexiones sin riesgo de dañar componentes.

10. Diagrama de conexión preliminar

Conexión preliminar en protoboard: el HC-SR04 usa dos pines digitales (Trig/Echo), el servomotor SG90 se conecta a un pin PWM, la pantalla LCD 16×2 se alimenta y comunica por sus líneas de datos, y los LEDs se conectan con resistencias de 220 Ω para limitar la corriente. Toda la alimentación y tierra se distribuyen desde el Arduino a través de la protoboard.

11. Algoritmo / pseudocódigo

  1. Iniciar el sistema: Arduino enciende y configura sensores, LEDs, servomotor, pantalla y demás componentes.
  2. Esperar un vehículo: el sensor de entrada detecta cuando un automóvil llega.
  3. Registrar la entrada: se guarda la hora de entrada y se activa el servomotor para abrir la barrera.
  4. Iniciar el conteo del tiempo: el sistema comienza a contar el tiempo de permanencia.
  5. Esperar la salida: Arduino monitorea hasta que el sensor de salida detecte al vehículo.
  6. Registrar la salida: se guarda la hora de salida y se calcula el tiempo total de permanencia.
  7. Calcular el costo: se aplica la tarifa establecida según el tiempo de permanencia.
  8. Mostrar el resultado: la pantalla LCD muestra el tiempo y el monto a pagar.
  9. Abrir la salida: tras el cobro, el servomotor abre la barrera para la salida del vehículo.
  10. Reiniciar el proceso: el sistema queda en espera del siguiente vehículo.
En resumen: Detectar entrada → Registrar hora → Contar tiempo → Detectar salida → Calcular costo → Mostrar costo → Abrir barrera → Reiniciar.

Funcionamiento

El HC-SR04 detecta el auto a menos de 5 cm; Arduino registra el tiempo con millis() y calcula la tarifa (base durante los primeros 5 minutos y proporcional después); el servomotor se mueve a 90° para levantar la pluma y se activan los LEDs.

Seguridad: usar siempre resistencias de 220 Ω con los LEDs, mantener la pluma ligera para no sobrecargar el SG90, y aislar Arduino y la protoboard de la pintura para prevenir cortocircuitos.

18. Criterios de éxito

El proyecto se considerará funcional cuando cumpla correctamente con:

  • Detección de entrada: el sensor detecta el vehículo y el sistema registra la hora sin intervención manual.
  • Control de la barrera: el servomotor abre al detectar el vehículo y cierra tras el ingreso.
  • Medición del tiempo: Arduino registra hora de entrada y salida, y calcula la permanencia correctamente.
  • Cálculo del costo: el resultado coincide con la tarifa establecida y el cálculo manual.
  • Detección de salida: el sensor de salida detecta correctamente cuando el vehículo se retira.
  • Visualización de información: la pantalla muestra el tiempo y el costo a pagar.
  • Funcionamiento general: el ciclo completo entrada → registro → conteo → salida → cálculo se ejecuta sin errores en pruebas consecutivas.
